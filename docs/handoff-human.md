## 現在做到哪

- **M0、M1、M2 全部完成**，都已 push 到 GitHub（最後 commit `6dc45fc`）。
- 網站可以：選書目 → 職業 → 背景 → 種族 → 屬性值（三種方式、可重骰）→ 技能與工具 → 語言 → 升級（1–20 級、兼職、子職）→ 法術 → 裝備 → 確認，然後看深色角卡（動作、法術、物品、特性與特質、背景、筆記、效果）。

## 你可以自己試

```
npm run build
```
然後雙擊 `dist/index.html`（不用開伺服器）。角色會自動存在瀏覽器；換電腦或換瀏覽器前記得按「匯出 JSON」。

如果是新電腦：先 `npm install`、`npm run fetch-data`、`npm run build-data`，再 `npm run build`。

## 等你回答的事（1 項）

**只有文字描述、沒有結構化資料的數值效果**（例如野蠻人／武僧的無甲防禦、「警覺」專長的先攻加值、「健壯」專長的 HP）：目前列在角卡「效果」分頁，要手動覆寫，不會自動算。
你希望「新人一來就什麼都算對」，但專案規則（CLAUDE.md §6）禁止人工對照表。請選：
- (a) 讓程式從原文自動解析常見句型（例如「AC 等於 10＋敏捷＋體質」），解析不了的仍要手動；
- (b) 允許少量人工寫的規則（較準，但要維護，且要改 CLAUDE.md §6）。
