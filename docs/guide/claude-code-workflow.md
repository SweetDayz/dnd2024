# 懶人操作手冊：用斜線指令推進專案

在 VS Code 打開 Claude Code 面板，輸入下列指令即可。

| 指令 | 做什麼 | 什麼時候用 |
|---|---|---|
| `/status` | 顯示各里程碑進度、待決事項、建議下一步 | 不知道做到哪時 |
| `/auto M1` | 自動連續做完整個里程碑，只有遇到必須你決定的事才停 | 最懶的用法 |
| `/next` | 只做下一個子任務，開工前會給你看簡短計畫 | 想邊做邊看、邊學時 |
| `/next M1-3` | 指定做某個子任務 | 想跳著做或重做時 |
| `/verify` | lint、測試、建置，並用無頭 Chrome 以 `file://` 實測 | 自己改過東西後 |
| `/refresh-data` | 從上游重新抓資料並比對差異 | 上游 5etools-cn 有更新時（M1 之後） |
| `/teach computed` | 用本專案的程式碼教你某個 Vue 概念或解釋某個檔案 | 看不懂時 |

## 建議節奏

1. 做完 M0-1 到 M0-3（安裝工具、建 repo、解壓這包檔案）。
2. `/auto M0` → 照它最後的提示，親自雙擊 `dist/index.html` 確認一次。
3. `/auto M1` → 回答它最後列出的待決事項（例如官方書目範圍）。
4. `/auto M2` → M2 很大，它可能會在每個子階段（M2a–M2e）結束時停下來給你看結果。

## 小技巧

- **讓它不要一直問權限**：Claude Code 跑指令或改檔前預設會詢問。在設定中可以把常用指令（`npm run *`、`git add`、`git commit`）加入允許清單，或在面板上選擇「這個 session 都允許」。push 和刪除檔案建議保留詢問。
- **中途想插話**：直接輸入訊息即可，它會在下一步之前看到。按 Esc 可以中斷。
- **context 太長**：一個里程碑跑完後可以開新對話再 `/status`，進度都記在任務檔和 git 裡，不會遺失。
- **做壞了**：每個子任務都有獨立 commit，可以叫它「回到 M1-2 完成時的狀態」。
