## M4-2 重印：預設隱藏所有被重印的版本

目前只處理「2014 被 2024 取代」，但上游網站的「重印」篩選是通用的：只要條目有被重印，預設就排除。

**已確認的事實**（上游 `cn2.0` commit `5cc0bbe`，寫任務檔時抽樣統計）：

- 欄位是 `reprintedAs`，值為 `"中文名|來源代碼"`，例如 `"汲能术|AU"`。**用的是簡體中文名，不是英文名**，比對時要用 `name`，不能用 `ENG_name`。
- 除了 `PHB→XPHB`、`DMG→XDMG`、`MM→XMM`，還有大量非 2014 的重印：

  | 類別 | 非 2014→2024 的重印（原來源→新來源：數量） |
  |---|---|
  | 法術 | `XGE→AU` 6、`SCC→AU` 1、`TCE→FRHoF` 1、`XGE→XPHB` 10、`TCE→XPHB` 9、`FTD→XPHB` 1 |
  | 種族 | `VGM→MPMM` 16、`ERLW→EFA` 21、`MTF→MPMM` 9、`VRGR→RHW` 3 等 |
  | 背景 | `ToA→EFA`、`ERLW→EFA`、`VRGR→RHW` |
  | 專長 | `TCE→XPHB` 10、`ERLW→EFA` 1 |
  | 可選特性 | `XGE→AU` 8、`TCE→EFA` 7、`TCE→XPHB` 15 |
  | 語言 | `SCAG→FRHoF` 11 等 |

  `AU` 是《启封奥秘 Arcana Unleashed》（2026-09-15）。使用者截圖中的負能量洪流、汲能術顯示為 AU，就是 `XGE→AU` 的重印。
- 以「名稱＋來源」在同一個檔案內找不到重印目標的：種族 17 筆、物品 12 筆、可選特性 19 筆。目標可能在其他檔案（子種族、`items-base.json`、`magicvariants.json` 等），要逐一查明解析方式，查不到的列進稽核報告（M4-5）。

- [x] 調查：寫小腳本重現上表（依目前的 `raw/` 版本），按資料類別分開，寫進 `docs/data-notes.md`。

## M4-5 資料完整性稽核（含語言）

使用者回報語言等資料明顯不全。先找出原因，不要逐項補。

- [x] 撰寫 `scripts/audit-data.ts`，並在 `build-data` 結束時自動執行：每個資料類別、每個 `source`，列出 `raw/` 的條目數與輸出的條目數；所有被丟掉的條目要列出**丟棄原因**（不在白名單、`_copy` 解析失敗、缺少必要欄位、被類型篩掉、被重印規則隱藏等）。結果寫到 `docs/data-audit.md`，終端機只印摘要。
- [x] 語言。**已確認的事實**（同上 commit）：
  - 遊戲語言資料在 `data/languages.json`，有 `language`（201 筆）與 `languageScript` 兩個陣列；英文名欄位是 `ENG_name`。
  - repo 根目錄的 `languages/` 資料夾是**網站介面的翻譯檔**（`zh_CN.json`、`zh-Hant.json` 等），不是遊戲資料，`fetch-data` 不需要抓。
  - `type`（`standard`／`exotic`／`rare`／`secret`）只有 105 筆有；另外 96 筆沒有 `type`，主要是 `MM` 21、`SCAG` 20、`XMM` 15、`MOT` 9 等怪物或設定書的語言。

  - 可能的原因（請逐一驗證）：建置時丟掉沒有 `type` 的條目、白名單沒涵蓋 `XMM`／`FRHoF` 等來源、或選單只顯示 `standard`。

  - 建角的語言選擇：依 2024 規則預設只列標準語言；提供開關「顯示稀有與其他語言（需 DM 同意）」。
