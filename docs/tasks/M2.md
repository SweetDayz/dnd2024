# M2：依書目建立角色＋深色角卡

> 本檔放在 `docs/tasks/M2.md`。前置條件：M1 已完成。總規範見根目錄 `CLAUDE.md`。
> 子階段依序執行，每個都可以單獨交付。M2 結束點可以視情況調整。

## 共通

- 角色資料模型 `src/rules/character.ts`：**只存玩家的選擇**（種族 id、背景 id、各職業等級與每級的選擇、屬性擲骰結果、裝備等），所有衍生數值由規則引擎即時計算，不存檔。
- 存檔格式要帶 `schemaVersion`，存在 localStorage，並提供 JSON 匯出與匯入。
- 每個選項旁都要有來源徽章。選項清單只列出目前啟用書目中的項目。
- 基準測試角色：岩地侏儒、侍僧背景、塑能師法師 12 級，數值要能對上 `docs/ref/ddb-screens.md`（例如法術 DC 17、雷鳴波 con17）。

## M2a 核心建角（1 級）

- [x] 建角精靈步驟：書目確認 → 職業 → 背景 → 種族 → 屬性值 → 技能與工具 → 語言 → 確認。
- [x] 屬性值有三種方式：4d6 去最低（可重骰並保留紀錄）、標準陣列、點數購買。
- [x] 背景的 +2/+1 或 +1/+1/+1 屬性加值，以及起源專長（2024 規則）。
- [x] 種族特質：體型、速度、黑暗視覺、抗性、語言、譜系選擇（例如侏儒譜系）。
- [x] 熟練來源合併；重複熟練時提示玩家改選其他項。
- [x] 規則引擎：調整值、熟練加值、技能、豁免、先攻、被動感知、HP（1 級）。
- [x] 效果自動偵測初版（見 CLAUDE.md §6，不做人工對照表）：用 XPHB 的全部種族特質與起源專長測試偵測結果，並把漏抓或誤抓的案例記錄在 `docs/data-notes.md`。

## M2b 升級、子職、兼職

- [x] 升級流程：每級列出該級獲得的特性與需要做的選擇（子職、屬性值提升或專長、職業選項、可選特性）。TCE 可選職業特性只在對應開關開啟時才出現，並標示「TCE 可選規則」。
- [x] HP：每級可選擲骰（允許重骰）或取平均值。
- [x] 兼職：檢查屬性前置條件、計算兼職熟練、合併施法者等級與法術位表。
- [x] 1 到 20 級都能建立。在建角流程中「未做選擇」要明確標示（DDB 的 No Choice Made）。

## M2c 法術

- [x] 依職業取得法術清單，戲法數、準備法術數依等級計算；處理法師法術書和儀式法術。
- [x] 處理來自種族或專長的法術（例如魔法入門），並各自記錄施法屬性與使用次數。
- [x] 法術列顯示：施法時間、射程、命中或 DC、效果與傷害（隨施法環位與戲法等級升階）、專注、儀式、材料，以及來源特性。

## M2d 裝備與戰鬥數值

- [x] 起始裝備：職業或背景的選項組（A/B）或改拿金幣；起始金額可擲骰並允許重骰。
- [x] 物品欄：重量、負重；盔甲與盾牌影響 AC；武器的精通（Weapon Mastery）與屬性。
- [x] 攻擊列：武器、徒手打擊、攻擊型戲法，計算命中與傷害；附上動作清單（攻擊、疾走、撤離等）。

## M2e 角卡畫面

- [ ] 深色主題，仿 DDB 版面：頂部摘要（名稱、種族、職業等級、AC、HP 上限、速度、熟練、先攻、被動感知）、六屬性與豁免、技能。
- [ ] 分頁：動作、法術、物品、特性與特質（可篩選職業、種族、專長）、背景（含特徵欄位，身高體重可擲骰）、筆記。
- [ ] 「效果」頁：列出所有會影響數值或擲骰的段落，每條標註來源（特性名｜類別｜書目頁碼），可展開原文。能推斷出對應欄位的，就在欄位旁放小圖示連到效果頁。
- [ ] 手動覆寫欄位，並清楚標示「已覆寫」。

## M2 完成標準

用 `file://` 開啟，在 `official` 書目下，從零建立基準角色並升到 12 級，角卡主要數值與 DDB 參考一致；JSON 匯出後再匯入，結果完全相同。
