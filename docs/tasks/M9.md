# M9：法術系統重整（取得方式 × 施放方式 × 版面）

> 本檔放在 `docs/tasks/M9.md`。前置條件：M2c 法術步驟已存在（本里程碑是重整，不是從零做）。總規範見根目錄 `CLAUDE.md`。
> 上游資料調查基準：`5etools-cn` `cn2.0` @ `5cc0bbe`（2026-10-24 抽樣統計）。開工前請以 `raw/VERSION` 重跑 M9-0 的統計腳本，若結果不同，以資料為準並更新本檔。

## 0. 現況問題（截圖：奇械師 4／法師 6（死灵师），總等級 10）

1. **法師的「法術書」和「準備法術」被拆成兩個分頁**，玩家要在兩份清單各勾一次。實際上它們是同一個法術的兩個階段：先抄進法術書，才能準備。正確的操作應該是在同一份清單、同一列點兩下（見 2.3）。
2. 「戲法、法術書、已知、準備、子職免費法術」全部擠在同一排分頁，命名也不一致：`奇械师準備法術 0/5` 有寫職業，`準備法術 0/10` 卻沒有。
3. 死灵师學派的 3 次免費抄寫被拆成 3 個 `死灵师・法術 0/1` 分頁，佔了兩排。
4. 同一個法術有多個來源時（例如寻获魔宠同時來自「法術書・死灵师」和「魔宠密友」），右側會重複出現兩列，看不出兩者的關係。
5. `亡者丧钟 感知 17` 容易被誤讀成「用感知施法」，實際意思是「目標做感知豁免，DC 17」，而 DC 是用智力算的。
6. 法術清單的高度限制和說明的顯示方式有問題（見 M9-6）。
7. 沒有顯示兼職合併後的法術位表（本例施法者等級 8，法術位為 4/3/3/2）。

右側「已學會的法術」的整體設計**保留**，只依本檔調整。

## 1. 核心模型：一個法術 × 多種「取得方式」

角色擁有的每個法術，都是一筆 **Grant**：`{ spellId, kind, sourceRef, ability, castModes[], countsToward? }`。
同一個法術可以有多筆 Grant。UI 合併顯示，但規則引擎分開計算。

### 1.1 取得方式（`kind`）

| kind | 中文標籤 | 是否占名額 | 資料欄位 | 例子 |
|---|---|---|---|---|
| `cantrip` | 戲法 | 占職業戲法數 | `cantripProgression` | 法師戲法 4 |
| `known` | 已知法術 | 占已知數 | `spellsKnownProgression` | 2014 吟遊詩人、術士、魔契師、遊俠、奧法騎士、詭術師 |
| `spellbook` | 法術書 | 占法術書數 | `spellsKnownProgressionFixed`（＋`…AllowLowerLevel`） | 法師 1 級 6 個，之後每級 2 個 |
| `prepared` | 準備法術 | 占準備數 | `preparedSpells`（公式）或 `preparedSpellsProgression`（陣列） | 法師**只能從自己的法術書選** |
| `always` | 永遠準備 | 不占 | `additionalSpells.prepared` | 領域法術、XPHB 遊俠的獵人印記 |
| `bonus` | 額外取得 | 不占 | `additionalSpells.known`（語意依宿主而定，見 1.2） | 學派學者、畸變心智 |
| `innate` | 天生施法 | 不占 | `additionalSpells.innate` | 卓尔的妖火、魔法學徒 |
| `arcanum` | 秘法奧義 | 每環各 1 個 | `spellsKnownProgressionFixedByLevel` | 魔契師 11/13/15/17 級 |
| `expanded` | 擴充清單 | **不是取得**，只是把法術加進可選清單 | `additionalSpells.expanded` | 2014 魔契師宗主、神聖之魂、奧法騎士的清單 |

**法術書制（法師）的兩階段**：一個法術的狀態只有三種，`未擁有 → 在法術書 → 已準備`。「已準備」一定也「在法術書」。規則引擎以這個狀態機為準，不允許出現「已準備但不在法術書」的資料。

**準備數的更換時機**（`preparedSpellsChange`）要顯示在標題上：
- `restLong`：「準備法術（長休後可全部重選）」。適用於牧師、德魯伊、法師、圣武士、遊俠、奇械師。
- `level`：「準備法術（升級時可替換一個）」。適用於 2024 吟遊詩人、術士、魔契師、奧法騎士、詭術師，也就是 2014 已知法術制在 2024 改名後的版本。

### 1.2 `additionalSpells.known` 的語意依宿主決定（重要）

5etools 用同一個 `known` 欄位表示不同的東西，必須依宿主的施法制度解讀：

| 宿主 | `known` 的實際意義 | Grant kind |
|---|---|---|
| 法師子職（2024 各學派的「學者」特性） | 免費加入法術書，不占法術書名額，之後仍需要準備才能施放 | `spellbook`（標記 `free: true`） |
| 已知法術制職業的子職（2014 遊俠 XGE、術士 TCE 等） | 額外的已知法術，不占已知數 | `known`（`free: true`） |
| 準備制職業的子職，戲法 | 額外戲法，不占戲法數 | `cantrip`（`free: true`） |
| 準備制職業的子職，1 環以上 | 視同永遠準備 | `always` |
| 種族、專長、背景、祈喚 | 戲法：直接學會；1 環以上：用該來源的屬性施放 | `cantrip` 或 `always` |

不確定的組合要寫進 `docs/data-notes.md`，並停下來問使用者。

### 1.3 施放方式（`castModes`，以徽章顯示）

| 資料 | 徽章 | 備註 |
|---|---|---|
| （一般） | 法術位 | 兼職時共用一套法術位 |
| `casterProgression: pact` | 契約法術位 | 與一般法術位分開計算 |
| `daily: {"1": [...]}` | 免費 1/長休 | `"1e"` 表示列出的每個法術**各** 1 次 |
| `rest: {...}` | 免費 N/短休 | |
| `resource: {"2": [...]}` ＋ `resourceName` | 消耗 功力 2 點 | 例如暗影武者 |
| `will: [...]` | 隨意施放 | |
| `ritual: [...]` | 只能以儀式施放 | 例如兽心道途、链之魔契 |
| 法術帶有 ritual 標記，且在法師法術書內 | 儀式施放 | 2024 法師的儀式專家：法術書內的儀式法術不必準備就能施放 |
| 2024 來源的種族或專長所給的天生 1 環以上法術 | 「也可用法術位」 | 例如 XPHB 魔法學徒、妖精觸碰、精靈譜系、提夫林遺產。判斷依據是來源的 `edition`，再用原文是否提到「法术位」做交叉檢查，不一致時記入 data-notes |

### 1.4 施法屬性（`ability`）

- 職業法術：使用該職業的 `spellcastingAbility`。
- `additionalSpells.ability` 有三種形式：
  - 固定值（例如 `"cha"`）。
  - `{ choose: [...] }`：由玩家選擇，在選擇器裡要有對應的下拉選單。
  - `"inherit"`：承接該專長本身所選的屬性加值，例如妖精觸碰選了 +1 智力，就用智力。
- 子職的 `additionalSpells` 若沒有寫 `ability`，就使用宿主職業的屬性。
- **每筆 Grant 各自計算 DC 與攻擊加值**。同一個法術從不同來源取得時，數值可能不同。

### 1.5 `additionalSpells` 解析規格（依 2026-10-24 統計）

- 外層陣列有多個元素時，代表**互斥選項，玩家只能選一個**。元素通常帶有 `name`／`ENG_name`，例如魔法學徒的牧師、德魯伊、法師三選一，大地結社的地形，巨人道途、魔射手的戲法二選一。
- 等級的 key：
  - `_`：取得該特性時立即獲得。
  - `"3"`：宿主等級 3。職業與子職看**職業等級**，種族與專長看**角色等級**。
  - `"s6"`：能施展 6 環法術時。用於 2014 魔契師擴充清單 `s1`～`s5`，以及 XPHB 吟遊詩人魔法奧秘的 `s6`～`s9`。
- 法術參照格式：`名稱|來源#c`。`#c` 表示戲法；沒寫來源時，依宿主版本推定（2014 宿主推定 PHB，2024 宿主推定 XPHB），推定失敗要記 warning。
- `choose` 有兩種形式：
  - 篩選字串，例如 `"level=0;1;2|class=法师|school=N"`、`"components & miscellaneous=仪式"`、`"source=EGW"`，可搭配 `count`。
  - 物件 `{ from: [...], count }`。
- `expanded` 裡的 `{ all: "level=1|class=牧师" }` 表示把整份清單加進可選範圍。

### 1.6 兼職與法術位

- `casterProgression` 的值有 `full`、`1/2`、`1/3`、`artificer`、`pact`。**XPHB 的圣武士與遊俠在資料中標記為 `artificer`**（減半後無條件進位），這點與 2014 的 `1/2` 不同，必須依資料計算，不可寫死。
- 每個職業「最高可學環位」只看該職業自己的等級，截圖中的做法是對的。法術位則依合併後的施法者等級計算。
- 戲法升階看**角色總等級**，不是職業等級。
- 2014 奧法騎士與詭術師的學派限制只寫在敘述文字裡，沒有結構化欄位。2014 版預設是隱藏的，所以只要在選擇器顯示提示文字即可，不做驗證，並記入 data-notes。

## 2. UI 設計

### 2.1 頂部：施法總覽

- 每個施法職業一張卡（保留現有的內容）。存檔 DC 一律寫成「法術 DC 17」，不要只寫屬性名稱。
- 新增一列 **法術位**：`法術位（施法者等級 8）　1環 4｜2環 3｜3環 3｜4環 2`。有魔契師時，再加一列 `契約法術位 2 個・3 環`。
- 新增「其他來源」卡，列出種族、專長、祈喚等法術來源，以及各自的屬性、DC 和攻擊加值。

### 2.2 左中：選擇導覽（取代現在那排分頁）

改成**依來源分組、每組內依步驟排序**的兩層結構，固定順序為：戲法 → 已知／法術書與準備 → 子職免費。

```
奇械師   戲法 2/2 · 準備 0/5
法師     戲法 4/4 · 法術書與準備（書 16/16・備 0/10） · 死灵师學派 0/3
其他來源 魔宠密友 ✓ · 高等精靈戲法 0/1
```

- 法師的「法術書」和「準備」合併成**同一個池子、同一份清單**，標題同時顯示兩個計數（見 2.3）。
- **同一個特性、同一種取得方式的選擇要合併成一個池子**。例如死灵师 3 次免費抄寫合併成 `死灵师學派 0/3`，池子裡再標示每格的限制：`≤2 環 ×2、≤3 環 ×1，限死灵系`。驗證時每一格各自檢查。免費抄寫進來的法術，之後一樣出現在「法術書與準備」清單中，可以再點一下設為準備。
- 選中某個池子後，標題列要顯示一句規則白話文，並附上來源徽章。例如：「從法師清單選死灵系法術，免費加入法術書，不占法術書名額。之後仍需要準備才能施放。」
- 「未選擇（No Choice Made）」的標示維持現狀。

### 2.3 中：法術清單

**法師（法術書制）：同一列點兩下的兩階段操作**

每一列最左邊是一個兩階段的勾選控制項，點擊時依序切換狀態：

| 目前狀態 | 點一下之後 | 計數變化 | 列的樣式 |
|---|---|---|---|
| 未擁有 | 抄進法術書 | 書 +1 | 書本圖示，一般亮度 |
| 在法術書 | 設為準備 | 備 +1 | 書本＋勾選圖示，高亮 |
| 已準備 | 移出法術書（同時取消準備） | 書 −1、備 −1 | 回到未擁有 |

- 只想取消準備、但保留在法術書時：在「已學會」那一列點「取消準備」，或在清單該列按右鍵（或長按）選「只取消準備」。
- **書已滿**時點未擁有的法術：不改變狀態，在列上提示「法術書已滿 16/16」。
- **備已滿**時點在法術書的法術：維持在法術書，提示「準備已滿 10/10」。
- **免費抄寫**（例如死灵师學派、寻获魔宠）的法術：起始狀態就是「在法術書」，並標示「免費」。只能在「在法術書」和「已準備」之間切換，不能移出法術書，也不占書的名額。
- **已由其他來源永遠準備**的法術（例如魔宠密友給的寻获魔宠）：「準備」這一階段鎖住，顯示「已由 魔宠密友 永遠準備」，避免浪費準備名額。仍然可以抄進法術書。
- 環位上限：抄寫與準備都受法師自身等級的最高環位限制（截圖中為 3 環）。
- 清單預設排序：已準備 → 在法術書 → 未擁有，各段內再依環位排序；可切換成單純依環位排序。提供篩選：全部／只看法術書／只看已準備。

**其他職業**

- 準備制（奇械師、牧師等）與已知制：維持單一勾選（一下＝選取），清單是整份職業法術清單。
- 每一列另加一欄「狀態」徽章：在法術書、已準備、已由 X 取得（不可重複選）、儀式。
- 互斥選項（例如魔法學徒選哪一個職業）在池子頂端用分段按鈕切換。

### 2.4 右：已學會的法術（保留現有設計並調整）

- **同一個法術合併成一列**，徽章依序列出每個來源，例如 `法術書・死灵师`、`永遠準備・魔宠密友`、`免費 1/長休`、`儀式施放`。如果各來源的施法屬性不同，點開後逐行顯示各來源的 DC、攻擊加值與使用次數。
- 目標要做豁免時，寫成「感知豁免 DC 17」；需要攻擊檢定時，寫成「命中 +9」。不可以只寫屬性名稱加數字。
- **在法術書裡但沒準備的法術**：列出但以灰色顯示，歸在可收合的「僅在法術書」群組，預設展開。若為儀式法術，加上「儀式施放」徽章。每一列有「準備」按鈕，效果等同在清單上點第二下。
- 頂端顯示計數：`戲法 6 · 準備 15 · 法術書 19 · 天生 2`。
- 「依來源／依環位」切換保留。

### 2.5 法術說明：右側詳情欄

- 不論在清單點法術名稱，或在「已學會」點一個法術，右欄都**切換成詳情模式**，最上面有「← 返回已學會」按鈕，按 Esc 也可以返回。切換時要保留「已學會」原本的捲動位置。（注意：點**名稱**是開詳情；點**最左邊的控制項**才是勾選，兩者不可混用。）
- 詳情內容依序為：中文名＋英文名、環位與學派、施法時間、射程、成分（材料全文）、持續時間、專注與儀式、完整內文（包含表格）、升環施放、職業清單、來源徽章、此角色取得的方式（Grant 列表，含各自的 DC），以及法師用的「抄進法術書／設為準備」按鈕。
- 詳情欄是 sticky，高度為 `calc(100vh - 頂欄高度)`，內容較長時在欄內自己捲動。這是整個畫面唯一允許的次要捲動區。
- 在清單上停留時，沿用 M1 的 tooltip 摘要。
