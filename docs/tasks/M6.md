# M6：審卡報告匯出（HTML／PDF）

> 本檔放在 `docs/tasks/M6.md`。前置條件：M4 已完成（M5 不是必要條件，兩者可以調換順序）。總規範見根目錄 `CLAUDE.md`。
> 取代 M3 的 xlsx 匯出，作為和 DM 審卡的主要管道。

## 目標

讓 DM 能快速核對角色是否合規：用了哪些書、每個數值怎麼來的、擲骰重骰了幾次、哪裡手動覆寫或還沒選。

## 格式決定

- **主要格式：單一自足的 `.html` 檔**（CSS 全部 inline、不需要 JS、不連網）。任何瀏覽器都能開，也能用 LINE、Discord、Email 傳給 DM。
- **不採用 MHTML**：MHTML 主要只有 Chromium 系列瀏覽器能直接開啟，手機和其他瀏覽器支援不穩，而它能做到的事單一 HTML 檔都做得到。
- **PDF：使用瀏覽器內建的「列印 → 另存為 PDF」**（`window.print()`＋列印專用 CSS）。不在瀏覽器內產生 PDF，因為那需要打包數 MB 的中文字型，違反 `file://` 單檔產物的精簡原則。
- 這三點寫進 `docs/data-notes.md`（§16，已完成）。若使用者之後仍需要 MHTML，再另開任務。

## M6-1 報告資料模型（純 TS）

- [x] `src/export/review.ts`：`buildReviewModel(character)` 只吃規則引擎算好的結果，不重新計算任何數值。
- [x] `renderReviewHtml(model)`：用字串模板產生完整 HTML，所有文字都要經過 HTML escape，`{@tag}` 一律轉成純文字。可以在 Vitest 中直接測試，不需要 DOM。

## M6-2 報告內容

順序如下，**警示區放在最前面**，讓 DM 一眼看到需要注意的地方：

1. **警示區**：手動覆寫的欄位、未完成的選擇（No Choice Made）、使用了 TCE 可選規則的項目、選了已有新版的重印舊版條目、套用 2014 相容規則的種族或背景。沒有任何警示時顯示「無」。
2. **摘要**：名稱、種族、背景、職業與等級、AC、HP 上限、速度、熟練加值、先攻、被動感知。
3. **書目與設定**：啟用的書目清單（使用 M4-1 的縮寫＋中文書名）、TCE 可選規則開關、重印開關、上游資料 commit hash、網站版本、匯出時間。
4. **屬性值明細**：產生方式；若是 4d6，列出**每一次擲骰與重骰紀錄**；每筆加值的來源（沿用 M4-4 的 `abilityBreakdown`）。
5. **逐級選擇表**：每一級的職業、獲得的特性、做的選擇（子職、ASI 或專長、可選特性、學會的法術），以及 HP 是取平均或擲骰（含重骰紀錄）。
6. **熟練、專精與語言**：每一項標註來源。
7. **法術**：依來源分組，含施法屬性、DC、攻擊加值、來源徽章。
8. **裝備與起始金額**：選了哪一組起始裝備或金幣，起始金額的擲骰紀錄。
9. **效果清單**：沿用 M2e 的效果頁內容，每條附來源。

共通規則：
- [x] 每個可選項目都有來源徽章（書名縮寫＋頁碼）。
- [x] 檔名：`<角色名>_Lv<總等級>_審卡_<YYYY-MM-DD>.html`，不合法的檔名字元要替換。
- [x] （可選）在 HTML 中以 `<script type="application/json">` 嵌入角色存檔 JSON，讓網站的「匯入」也能直接吃這個 HTML 檔。若實作，匯入端要加測試；若不做，記錄在待決事項。

## M6-3 外觀與列印

- [x] 螢幕上顯示用深色主題（與網站一致）；`@media print` 改為白底黑字，A4 直式。
- [x] 列印時表格不在列中間斷頁，表頭每頁重複，各大段落之間可分頁。
- [x] 字型只用系統字型（例如 Microsoft JhengHei、PingFang TC、Noto Sans TC），不嵌入字型檔。

## M6-4 UI

- [x] 角卡頁頂部新增「審卡報告」按鈕，開啟報告預覽畫面，內有兩個按鈕：「下載 HTML」與「列印／存成 PDF」。
- [x] 第一次使用時顯示簡短說明：「下載的 HTML 可直接傳給 DM 用瀏覽器打開；要 PDF 請按列印，目的地選『另存為 PDF』。報告是快照，修改角色後要重新匯出。」並提供「不再顯示」。

## M6-5 測試

- [x] Vitest：用基準角色（岩地侏儒、侍僧背景、塑能師法師 20 級；原寫 12 級，但 DC 17 是 20 級的值，見 data-notes §13 第 6 項）產生 HTML，驗證含有法術 DC 17、所有段落標題、警示區、沒有殘留 `{@`、沒有未 escape 的使用者輸入（用含 `<script>` 的角色名測試）。
- [x] `check:file`：點擊「下載 HTML」觸發下載且沒有 console error；再用 `file://` 開啟下載的檔案，主控台零錯誤、不發任何網路請求。

## M6 完成標準

1. 以 `file://` 開網站，匯出基準角色的審卡 HTML，用另一個瀏覽器（或手機）開啟正常、中文無亂碼。
2. 使用「列印 → 另存為 PDF」得到白底、排版正常的 A4 PDF。
3. 警示區正確列出手動覆寫、未選擇、TCE 可選規則與重印舊版。
4. `npm test`、`check:file` 全部通過。
