# M1：資料管線＋書目篩選

> 本檔放在 `docs/tasks/M1.md`。前置條件：M0 已完成。總規範見根目錄 `CLAUDE.md`。

## 目標

建置期抓好資料，網站開啟後可以用「官方」預設群組篩選書目，並依類別瀏覽所有可選項目，每項都清楚標註來源。**這個階段還不建立角色。**

## 任務

### M1-1 抓取資料
- [x] 撰寫 `scripts/fetch-data.ts`：從 `https://github.com/tjliqy/5etools-cn` 的 `cn2.0` 分支，只取 `data/` 目錄（用 git sparse checkout 或下載 tarball）到 `raw/`，並把使用的 commit hash 記錄在 `raw/VERSION`。
- [x] 預期需要的檔案如下，實際檔名以 repo 為準：`books.json`、`adventures.json`、`class/*.json`、`spells/*.json`（以及法術與職業的對照，可能在 `generated/` 裡）、`races.json`、`backgrounds.json`、`feats.json`、`items.json`、`items-base.json`、`optionalfeatures.json`、`languages.json`、`skills.json`、`conditionsdiseases.json`。
- [x] **調查 schema**，把以下發現寫進 `docs/data-notes.md`：
  - 每類資料的關鍵欄位、`_copy` 的用法、英文名欄位（若有）、reprint 相關欄位。
  - `{@tag}` 的種類統計。
  - **TCE 可選規則的辨識方式**：可選職業特性、背景或起源相關的可選規則各用什麼欄位標記。

### M1-2 來源白名單與群組
- [x] 從 `books.json` 與 `adventures.json` 產生「代碼 → 中文名 → 英文名 → 出版日期 → 類型（規則書或冒險）」的對照表。
- [x] 在 `src/data/sourceGroups.ts` 定義群組 `official`。**官方書目的確切範圍之後再定**，先放一份暫定清單（WotC 出版、內含玩家選項的書），並把完整對照表輸出到 `docs/data-notes.md`，讓使用者之後勾選。

### M1-3 建置資料
- [x] 撰寫 `scripts/build-data.ts`：
  - 解析 `_copy` 與 `_mod`。
  - 只保留白名單來源的條目。
  - 為每筆資料加上統一 id：`kind|name|source`。
  - 標記 reprint 關係。
  - 標記 TCE 可選規則旗標。
  - 只保留建角需要的欄位以縮小體積，並在建置時印出每個輸出檔的大小。
  - 輸出到 `public/data/*.js`（classic script 格式，見 CLAUDE.md §3）。
- [x] 單元測試：`_copy` 解析、白名單過濾、reprint 標記、TCE 旗標。

### M1-4 內文渲染
- [x] 撰寫 5etools `entries` 結構的渲染器，處理 `entries`、`list`、`table`、`inset` 等型別。
- [x] 撰寫 `{@tag}` 渲染器，至少支援 spell、item、condition、damage、dice、dc、skill、feat、class、creature、filter、b、i；遇到未知標籤時顯示純文字並記錄 warning。
- [x] 可連結的標籤要有 hover tooltip，內容為該條目的摘要。

### M1-5 書目篩選 UI
- [x] 書目篩選面板：可一鍵套用 `official` 群組，並顯示目前啟用的書目清單。單本勾選介面先保留位置、隱藏起來。
- [x] 開關：「顯示已被取代的 2014 舊版」，預設關閉。
- [x] 開關：「TCE 可選規則」，預設關閉。
- [x] 篩選狀態存在 localStorage。

### M1-6 選項瀏覽器
- [x] 分類分頁：種族、背景、職業（含子職）、專長、法術、物品、可選特性。
- [x] 每項顯示中文名、英文名（若有）、來源徽章（書名＋頁碼）、2014 或 2024 標記；點開可看完整內文。
- [x] 提供文字搜尋，並可依法術環位、學派、職業做基本篩選。
- [x] 每個分頁顯示「目前書目下共 N 項」。

## M1 完成標準

1. 用 `file://` 開 `dist/index.html`，套用 `official` 後，各分頁的項目數量與上游網站相同篩選條件下大致吻合，並在 `docs/data-notes.md` 記錄比對結果。
2. 任一條目都看得到來源書與頁碼。
3. 關閉任一本書後，該書的條目就消失；預設不會出現已被重印取代的 2014 條目。
4. `npm test` 全部通過。
