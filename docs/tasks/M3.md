# M3：匯出角卡為 Excel 檔（給 Google 試算表用）

> 本檔放在 `docs/tasks/M3.md`。前置條件：M2 已完成。總規範見根目錄 `CLAUDE.md`。

## 目標

角卡頁面有一個「匯出試算表」按鈕，在瀏覽器端直接產生 `.xlsx` 下載。使用者把檔案拖進 Google Drive、用 Google 試算表開啟後，就能在「備註」欄寫東西，或用 Google 內建的註解功能和 DM 討論。

**範圍界線**：匯出後的檔案由使用者自己管理。本站**不**讀回 xlsx、**不**串接 Google API、**不**在網站內做註解功能。

## 任務

### M3-1 選擇函式庫
- [ ] 比較 **ExcelJS** 與 **SheetJS Community Edition**（注意：npm 上的 `xlsx` 套件是舊版，SheetJS 官方要求從 `https://cdn.sheetjs.com` 的 tarball 安裝）。評估標準：
  - 在 `file://` 下能正常產生並下載檔案（使用 Blob ＋ `<a download>`，不發網路請求）。
  - 打包後增加的 `index.html` 大小。
  - 能否設定欄寬、凍結標題列、標題列粗體。
  - 授權條款。
- [ ] 把比較結果和選擇寫進 `docs/data-notes.md`，然後安裝。

### M3-2 工作表設計
匯出邏輯放在 `src/export/xlsx.ts`。它只吃規則引擎算好的角色資料，不重新計算任何數值。

| 工作表 | 內容（每列一個項目） |
|---|---|
| 摘要 | 名稱、種族、背景、職業與等級、AC、HP 上限、速度、熟練加值、先攻、被動感知、六屬性（值／調整值／豁免）、技能 |
| 動作 | 攻擊列與動作清單（名稱、類型、射程、命中或 DC、傷害、備註） |
| 法術 | 環位、名稱、英文名、施法時間、射程、命中或 DC、效果、專注／儀式／材料、來源特性 |
| 物品 | 名稱、數量、重量、是否裝備、是否同調、價值（M2 的物品欄還沒有「同調」欄位，需先在 `InventoryItem` 加上並在物品欄提供勾選） |
| 特性與特質 | 名稱、類別（職業、種族、專長、背景）、取得等級、內文純文字 |
| 效果 | 對應 M2e 的效果頁：段落摘要、推斷影響的欄位、來源 |
| 背景 | 背景、陣營、身高、體重、個性特質、理想、羈絆、缺點、外貌 |
| 關於 | 匯出時間、網站版本、上游資料 commit hash、目前啟用的書目清單、TCE 可選規則開關狀態 |

共通規則：
- [ ] 除了「摘要」和「關於」，每張表最右邊固定一欄空白的「備註」，欄寬要夠寫字。
- [ ] 每個可選項目都要有「來源」欄（書名＋頁碼），讓 DM 可以核對。
- [ ] 標題列凍結並加粗；欄寬依內容設定合理值；長文字欄位要自動換行。
- [ ] 5etools 的 `{@tag}` 要轉成純文字，不可殘留標籤語法。
- [ ] 檔名格式：`<角色名>_Lv<總等級>_<YYYY-MM-DD>.xlsx`；角色名有不合法的檔名字元時要替換掉。
