# M5：法術選擇重新設計

> 本檔放在 `docs/tasks/M5.md`。前置條件：M4 已完成（重印規則、來源縮寫、共用搜尋修正）。總規範見根目錄 `CLAUDE.md`。
> 參考：上游網站的法術列表（可排序的表格）與篩選面板（三態標籤、AND/OR）。

## 目標

選法術時，不用點開每一道法術就能看到環階、專注、儀式、成分、學派、耗材、施法時間與持續時間；可以像上游網站一樣篩選；隨時看得到角色已經從各種來源學會哪些法術，避免重複選。

## M5-1 調查欄位

- [ ] 實際抽樣 `raw/` 的法術資料，確認以下資訊各在哪個欄位，寫進 `docs/data-notes.md`（**不要憑記憶假設**）：環階、學派、子學派、成分（V／S／M、材料花費、是否消耗）、儀式、專注、施法時間、持續時間、射程、範圍形狀、傷害類型、造成的狀態、法術攻擊、豁免、屬性檢定、影響的生物類型、其他雜項標籤（例如上游的「傳送」「召喚生物」等）。
  已知線索（上游 `cn2.0` commit `5cc0bbe` 抽樣，969 道法術）：`components`（M 為物件時有 `cost` 172 道、`consume` 85 道）、`duration[].concentration`（423 道）、`meta`（儀式等，68 道）、`miscTags` 721、`areaTags` 643、`damageInflict` 361、`savingThrow` 406、`conditionInflict` 184、`spellAttack` 65、`abilityCheck` 57、`affectsCreatureType` 77、`scalingLevelDice` 41。仍需實際確認各欄位的值域。
- [ ] 「哪些職業、子職、種族、背景、專長、其他特性可以取得這道法術」使用 `data/generated/gendata-spell-source-lookup.json`。它的第一層是小寫的來源代碼、第二層是簡體中文法術名，內含 `class`、`subclass`、`classVariant`、`race`、`background`、`feat`、`optionalfeature`、`reward` 八種鍵。
  - `classVariant` 很可能是 TCE 的擴充法術清單，需確認；若是，就只在「TCE 可選規則」開關開啟時才納入職業法術清單，並標示「TCE 可選規則」。
  - `reward`（祝福、魔力恩賜等）不屬於建角，預設不納入篩選。
- [ ] 在 build-data 中，把這些欄位整理成扁平的索引欄位，讓篩選不必在執行期解析巢狀結構；印出法術檔大小的變化。

## M5-2 篩選邏輯（純 TS）

- [ ] `src/data/spellFilter.ts`：純函式＋ Vitest。
- [ ] 每個篩選群組的每個標籤都是三態：**包含**（藍）、**排除**（紅）、**不篩選**；群組可切換 AND／OR；提供「全選」「清除」「預設」。
- [ ] 支援的群組（依使用者提供的上游清單，資料沒有的欄位就略過並記錄）：來源、環階、職業、種族、背景、專長、其他選項／特性、成分與雜項、組別、學派、子學派、傷害類型、造成的狀態、法術攻擊、豁免、屬性檢定、施法時間、持續時間、射程、範圍形狀、影響的生物類型。
- [ ] 「成分與雜項」至少包含：專注、儀式、V、S、M、有花費的材料、會消耗的材料、重印。
- [ ] **預設值**：來源＝目前啟用的書目；重印＝排除（依 M4-2 規則）；其餘不篩選。
- [ ] **選擇欄位的限制優先於篩選**：目前分頁是「法術書」時，候選範圍先限定為法師法術清單且環階不超過可學最高環，篩選只能在這個範圍內再縮小。
- [ ] 文字搜尋比對中文名與英文名，不包含已勾選但不符合的項目（M4-3）。
- [ ] 效能：在全部法術上套用多個篩選與排序，耗時要在 50ms 以內（寫一個簡單的 benchmark 測試）。

## M5-3 法術表格

- [ ] 欄位：勾選、名稱（中文＋英文）、環階（戲法顯示「戲法」，儀式加註）、施法時間、學派、專注（×）、射程、持續時間、成分（例如 `V S M★`，★ 表示材料有花費，另一個符號表示會消耗）、來源徽章。
- [ ] 每一欄都可以點標題排序；預設依環階、再依名稱排序。
- [ ] 不符合目前選擇欄位條件的法術（例如環階太高）不出現在表格中；可用一個開關改為「顯示但反灰」，並在 tooltip 說明原因。
- [ ] 已經從其他來源取得的法術：仍然顯示，但標註「已由 種族：XXX 取得」。同一選擇欄位內不可重複；跨來源重複時顯示警示但允許勾選（例如把種族法術抄進法術書）。實際規則若有疑義，記到「待決事項」。
- [ ] 選滿時，其他列的勾選框停用，並提示「已選滿 14/14」。
- [ ] 點選一列（不是勾選框）時，在下方詳情區顯示完整內文、升環效果、可用職業與來源。

## M5-4 選擇欄位分頁

- [ ] 表格上方以分頁列出這個角色所有的法術選擇欄位，例如「法師戲法 4/4」「法術書 2/14」「準備法術 0/9」「魔法入門（法師）1/2」。每個分頁顯示已選數與上限，未選完的標紅（沿用 No Choice Made 的標示）。
- [ ] 「準備法術」分頁的候選範圍是法術書內的法術（加上可準備的其他來源），不是整份職業清單。
- [ ] 戲法與一環以上法術分開成不同欄位，不混在同一張表。

## M5-5 右側「已學會的法術」

- [ ] 彙整角色**所有來源**的法術（職業、子職、種族、背景、專長、其他特性），沿用並取代目前頁面下方的「法術一覽」。
- [ ] 可切換依「來源」或依「環階」分組。
- [ ] 每道法術顯示狀態標籤：戲法、法術書、已準備、永遠準備、免費施放（次數／休息類型）、儀式施放。
- [ ] 每個來源顯示其施法屬性、法術 DC、法術攻擊加值（例如種族法術用的屬性可能和職業不同）。
- [ ] 點擊右側項目，會在左側表格定位並顯示詳情。

## M5-6 狀態保存與測試

- [ ] 每個選擇欄位的篩選與排序狀態存在 localStorage（UI 偏好，不進角色存檔）；提供「重設為預設」。
- [ ] Vitest：三態篩選與 AND／OR、預設篩選、選擇欄位限制、重複偵測、選滿停用。
- [ ] 以基準角色（塑能師法師 12 級）完整走一次選法術流程，`check:file` 加上法術頁的 smoke check。

## M5 完成標準

1. 不點開任何法術，就能在表格中看到環階、專注、儀式、成分、學派、耗材、施法時間、持續時間與來源。
2. 篩選面板涵蓋上述群組（資料沒有的欄位已記錄），預設排除重印版本。
3. 右側隨時顯示全部已學會的法術；重複選擇會被提示。
4. `npm test`、`check:file` 全部通過。
