# /status：進度總覽

只讀檔案，不修改任何東西。

1. 讀 `docs/tasks/` 底下所有 `M*.md`，統計每個子任務的勾選項目：已完成數 / 總數。
2. 讀 `docs/data-notes.md` 的「待決事項」區（若檔案存在）。
3. 執行 `git log --oneline -5`。

輸出格式：

```
M0 本機環境      ██████████ 100%
M1 資料與篩選    ████░░░░░░  40%  ← 進行中（下一個：M1-3 建置資料）
M2 建立角色      ░░░░░░░░░░   0%

最近 commit：
  ...

待決事項（N）：
  1. ...

建議下一步：輸入 /next 或 /auto M1
```

若有標示「你自己做」但看起來還沒完成的項目，特別提醒。
